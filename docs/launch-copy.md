# Texto de apresentação

## Curto

**Suas contas. Seu saldo. Seus apps. Um só gerenciador.**

O Codex Account Manager reúne organização de contas, grupos, limites de uso e integrações locais em um app desktop para Linux e Windows. Você escolhe quais recursos cada aplicação pode usar; a CLI e os SDKs Python/TypeScript fazem a ponte com seus projetos.

Rust + Tauri + Svelte. Código MIT. Independente, experimental e com limitações conhecidas documentadas.

## Para desenvolvedores

Quer usar uma conta específica do Codex num projeto e manter as outras organizadas? O Codex Account Manager oferece um fluxo local de autorização para suas aplicações: escolha contas ou grupos na interface, use execuções efêmeras ou construa seu harness com App Server. Sem editar credenciais diretamente e sem um cadastro extra de vínculo depois da aprovação.

Não é um provedor de contas, não inclui assinatura e não contorna limites do serviço. É uma ferramenta para organizar recursos que você já está autorizado a usar.

[Conheça o projeto e as releases](https://github.com/KingDonRush/codex-account-manager).
