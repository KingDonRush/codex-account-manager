# Componentes de terceiros

A licença MIT deste repositório cobre o código autoral do projeto, não altera licenças de dependências e não concede direitos sobre marcas.

- Rust/Tauri e os crates usados pelo backend conservam suas licenças. As versões e origens estão em `src-tauri/Cargo.lock`.
- Svelte, TypeScript, Vite, Playwright e dependências JavaScript conservam suas licenças. As versões e origens estão em `package-lock.json`.
- Pacotes que incluem Chrome for Testing/Chromium devem conservar os avisos e arquivos de licença fornecidos com esse runtime. Seu conteúdo não deve ser tratado como código MIT deste projeto.
- WebView2, bibliotecas do sistema e o aplicativo Codex possuem termos próprios. O projeto não inclui nem substitui uma licença de uso do Codex.
- Os arquivos de chave pública usados para verificar assinaturas não são chaves privadas nem concedem autoridade de assinatura.

Este projeto é independente e não é afiliado, patrocinado ou certificado pela OpenAI, Google, Microsoft ou pelos responsáveis pelas bibliotecas utilizadas.
